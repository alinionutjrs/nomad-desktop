# Audit Nomad — 10 noiembrie 2026

## Verificat pe Windows x64

- Build Tauri 2 0.1.2: executabil, instalator NSIS și semnătura updater generate.
- 28 teste Rust și 3 teste TypeScript: toate trec.
- Aplicația 0.1.2 a fost pornită direct din build și inspectată în interfața reală.
- Proiectul starter `nomad-audit` a fost deschis; lista de fișiere și editorul funcționează.
- O schimbare în `index.html` a produs un diff, a fost aprobată și a apărut pe disc și în preview.
- Dev server-ul a pornit pe localhost, a afișat loguri și s-a oprit din UI.
- Când serverul este oprit, preview-ul afișează starea oprită; dacă portul este ocupat, Nomad avertizează înainte să pornească alt proces.
- Paginile General și Furnizori AI au fost inspectate vizual după repararea layout-ului.
- Rezultatele uneltelor AI de listare și căutare exclud căile sensibile; un test automat verifică acest lucru.

## Încă neverificat sau incomplet

- Instalatorul NSIS nu a fost parcurs complet: controlul automat al ferestrei de instalare a fost respins de sistem. Instalarea existentă rămâne la versiunea anterioară; executabilul nou a fost testat direct.
- Pachetele macOS și Linux nu pot fi construite sau rulate nativ pe această gazdă Windows. Workflow-ul GitHub pentru ele folosește runners macOS 15 și Ubuntu 22.04; buildurile remote cer secretul `TAURI_SIGNING_PRIVATE_KEY`.
- Streaming AI real și conturile Claude Code/Codex nu au fost testate fără credențiale și servicii configurate.
- Conturi cloud, abonamente și credite, sincronizare Neon/Supabase, deploy extern și conectarea efectivă la servere MCP sunt încă neimplementate. Secțiunile aferente din Setări arată configurații locale și limitele curente.
- Nu a fost efectuat un test complet al fiecărei pagini de setări, al fiecărui provider sau al fiecărui flux de Git/export pe toate trei sistemele de operare.

## Următorii pași pentru release

1. Instalează manual `Nomad_0.1.2_x64-setup.exe` peste versiunea anterioară și verifică lansarea din Start Menu.
2. Configurează secretul de semnare Tauri în GitHub Actions și rulează workflow-ul de release pentru pachetele native macOS/Linux.
3. Verifică pachetele pe mașini reale macOS și Linux, apoi publică downloadurile și feed-ul de actualizare.
4. Configurează furnizori AI de test și un backend cloud de test înainte de validarea fluxurilor externe.
