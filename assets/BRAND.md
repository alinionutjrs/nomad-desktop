# Nomad visual identity

## Idea

Nomad turns a route into a working application. The mark combines an original geometric N with a north-star glint: a clear direction, a path through code, and the user's control of the destination. The gradient moves from the product's signature field green into a calm mint, signaling craft and motion without looking like a generic AI sparkle.

## Core palette

| Name | Hex | Use |
| --- | --- | --- |
| Trail Green | `#B7F36B` | Primary actions and light surfaces |
| Waypoint Mint | `#66DEC3` | Gradient accent and active details |
| Night Camp | `#101713` | Icon, dark surfaces |
| Field Ink | `#0B0E0A` | Main canvas |
| Mist | `#EAF1E8` | Primary text |
| Stone | `#849287` | Supporting text |

## Assets

- `public/nomad-mark.svg`: square app and avatar mark.
- `public/nomad-wordmark.svg`: horizontal brand lockup.
- `public/nomad-social.svg` and `.png`: product share card (1200 × 630).
- `public/nomad-app-icon.png`: 512 px web touch icon.
- `src-tauri/icons/`: generated platform icon sizes, ICO and ICNS.

Use the mark on its dark rounded square; retain clear space of at least one eighth of its width. Do not add shadows, skew, or recolor the mark. The wordmark is lowercase and uses the system UI family so it stays crisp across operating systems.
